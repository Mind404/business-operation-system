## 五、遗留风险（不阻塞验收）
1. **外部插件令牌无轮换/吊销界面**。当前令牌按插件稳定派生，换 `SECRET_KEY` 会让所有插件令牌一起失效。接入方多起来后建议补单插件轮换。
2. **外部事件接口无速率限制/重放保护**。幂等依赖稳定 `business_key`；如果调用方每次重试换新键，仍可能重复建单。生产接入时应由插件侧保证稳定业务键。
3. **旧模板 `workflow_admin.html` 仍在代码里但不再渲染**。保留用于回滚排查，不影响新入口；后续可清理。
4. **直通记录包含业务结果事件**。例如项目审批完成后的“项目审批结果”节点未配置时也会记一条直通，数量会比“用户绕过审批”的实际业务多。看数量时需结合节点名称判断。

## 六、验收建议
1. 用管理员进“审批中心 → 规则配置”，编辑“项目创建”，把范围改成“指定项目类型：交付项目”。
2. 用普通账号新建交付项目，确认待审批、审批人正确。
3. 分别用主审批人、备份人各走一次，确认兜底。
4. 新建研发项目，确认未配置直通且能在直通记录中看到。
5. 用外部插件按 `插件流程接入规范_v13.8.md` 上报一次，确认无规则直通、有规则进审批。
