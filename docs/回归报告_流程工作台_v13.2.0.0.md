- 默认进入简易模式：按顺序添加审批节点，选择节点名称、审批人类型、审批人值、审批方式和通过后动作。

- 提交后由后端编译为既有流程定义，再交给 SpiffWorkflow 内核执行；运行中的实例继续使用发布时版本。
- JSON 编辑折叠到高级模式，仅供平台管理员/开发使用，不再作为业务人员默认界面。
- 发起流程页默认只显示模板、标题、业务单号；插件 ID、记录类型、记录 ID、上下文 JSON 放入高级选项。
