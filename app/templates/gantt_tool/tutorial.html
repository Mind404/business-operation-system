一、快速开始（3 步）

  1. 解压本压缩包，进入 甘特图工作计划工具 文件夹；
  2. Windows：双击 start.bat；Mac / Linux：运行 start.sh 或 python3 server.py；
  3. 浏览器会自动打开工具页面，即可开始使用。

如果浏览器没有自动打开，请手动访问：http://127.0.0.1:8000

电脑需要安装 Python 3（无需安装任何第三方库，标准库即可运行）。在命令行输入 python --version 可查看是否已安装。
# 也可在命令行手动启动，支持指定端口 python server.py python server.py 9000 # 指定端口 9000 python server.py 9000 --no-browser

二、界面介绍

▲ 主界面：左侧分类任务面板 + 统计卡片 + 表格 + 甘特图

界面为白色简洁风格，从上到下、从左到右分别是：

区域说明
顶部工具栏添加项目、使用教程、导出数据、导入数据、示例数据、清空
左侧「任务名称」面板按 产品研发情况 / 产品测试情况 / 产品生产情况 三个分类管理任务，每个分类可单独「＋ 新增」；点击分类或分类下的任务即可筛选
统计卡片全部项目及各分类的任务数量与完成率，点击卡片可切换筛选
环形图整体项目完成率
任务表格序号、是否完成、工作项目名称、开始/结束日期、分类、操作（编辑/删除）
甘特图按时间轴展示每个任务的时间跨度；已完成任务带 ✓，虚线为今天
全屏自适应：页面会自动占满整个浏览器窗口，所有元素随屏幕大小等比缩放——大屏不会缩成一小块、小屏也不会挤压变形。任务天数较多时，在甘特图区域底部左右拖动即可查看完整时间轴（左侧表格列始终固定）；按 F11 可进入浏览器全屏获得更大显示区。

三、新增任务

有两种方式：

  1. 点击顶部「＋ 添加项目」：在弹窗中填写名称、日期，并从「分类」下拉框选择所属分类；
  2. 点击左侧某个分类旁边的「＋ 新增」：分类会自动带出，直接填写即可。
▲ 添加项目弹窗（分类已自动选中「产品研发情况」）
  • 工作项目名称：必填，例如「V1.3基础协议适配开发」；
  • 开始日期 / 结束日期：必填，结束日期不能早于开始日期；
  • 分类：产品研发情况（蓝）/ 产品测试情况（橙）/ 产品生产情况（绿），决定甘特条颜色与左侧归类；
  • 是否已完成：可勾选，也可在表格「是否完成」列随时切换。
在弹窗中按 回车 可直接保存；按 Esc 或点「取消」关闭。

四、编辑、完成、删除

  • 切换完成状态：点击表格「是否完成」列的 ☐/☑ 即可；
  • 编辑：点击任务所在行的「编辑」按钮，修改后保存；
  • 删除：点击「删除」按钮，确认后删除该任务。

所有操作都会自动保存到本目录的 data.json，无需手动点保存。

五、分类筛选与统计

  • 点击左侧「全部项目」或任意分类（含分类头部、分类下的任务行），表格和甘特图会只显示该分类的任务；
  • 点击顶部任意统计卡片，效果相同；
  • 统计卡片实时显示各分类任务数与完成率，环形图显示整体完成率。

六、计划时间范围

  • 自动范围：勾选后时间轴自动跟随所有任务的起止日期；
  • 手动范围：取消勾选后，可自行修改开始/结束日期（适合固定周期的计划表，如按月排期）。

七、数据导出 / 导入（备份与复用，支持 Excel）

  1. 导出数据：点击「⬇ 导出数据 ▾」，可选择
    • 导出为 JSON 文件（.json）：完整备份，含分类、完成状态、时间范围设置；
    • 导出为 Excel 文件（.xlsx）：直接用 Excel / WPS 打开，可编辑后再导回，表格列为 序号 / 是否完成 / 工作项目名称 / 开始日期 / 结束日期 / 分类。
  2. 导入数据：点击「⬆ 导入数据」选择 .json 或 .xlsx 文件，即可完整恢复任务与设置。
  3. Excel 导入规则：带表头（推荐用工具导出的文件修改）与无表头（按 名称/开始/结束/分类/完成 列序）都支持； 完成列可写 是/否、1/0、true/false、√；日期支持 2026-09-01、2026/9/1 及 Excel 日期序列号。
  4. 也可以直接备份 / 拷贝工具目录下的 data.json。
换电脑使用：把整个文件夹拷走，或在新电脑上「导入数据」选择 JSON / Excel 文件即可，数据完全复用。

八、示例数据 / 清空

  • 示例数据：一键载入内置示例（三个分类共 10 条任务），适合首次体验；
  • 清空：清空所有任务（建议先导出备份）。

九、内网部署（局域网多人使用）

  1. 在一台装有 Python 3 的内网电脑上启动工具（双击 start.bat）；
  2. 启动后命令行会显示本机局域网地址，例如 http://192.168.1.100:8000；
  3. 同一局域网内其他电脑，用浏览器打开该地址即可共同查看 / 编辑（数据统一保存在这台电脑上）。
若无法访问，请检查系统防火墙是否放行对应端口（如 8000）。

十、常见问题

问题解决办法
双击 start.bat 闪退在命令行运行 python server.py 查看报错信息；确认 Python 3 已安装
端口被占用换端口启动：python server.py 9000
数据不见了检查同目录 data.json 是否还在；文件损坏时会自动备份为 data.json.bak-时间 并恢复示例数据
想换个浏览器打开手动访问命令行中显示的地址即可
