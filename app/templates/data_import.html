导入说明

CSV 格式要求

  • 文件编码：UTF-8
  • 第一行：字段名（需与数据库字段一致）
  • 每行：一条记录，字段用逗号分隔
  • id 字段可省略（自动递增）

JSON 格式要求

  • 顶层必须是数组 []
  • 每个元素是一个对象，键名为字段名
  • 示例：[{"title": "需求1", "quantity": 100}, ...]

注意事项

  • 导入前建议先 导出 SQL 备份
  • 导入失败的记录会被跳过，不会中断整体导入
  • 必填字段为空会导致该条记录导入失败
